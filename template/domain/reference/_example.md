# Example Reference Page

Delete this file. It shows the shape of a `reference/` page: a stable statement of how something is or should be - a guideline, commandment, or baseline - independent of any single task.

- Lead with the rule, then the rationale.
- Link related pages with `[[wikilinks]]` - they resolve repo-wide, so keep page basenames unique across the whole repo.
- Tags are kebab-case: `azure-functions`, not `AzureFunctions`.
- Keep it evergreen; task-specific steps belong in `how-to/`.
