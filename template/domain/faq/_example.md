# Example FAQ

Delete this file. One question per `##` heading, a short answer below, and a link to the fuller page when one exists.

## What goes in an FAQ vs a reference page?

Short answers to real questions go here. If an answer grows into an essay, graduate it to a `reference/` or `how-to/` page and leave a one-line pointer here.
